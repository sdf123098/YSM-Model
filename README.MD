# YSM-Model — 免费 YSM 模型资源站

一个完全免费的 **Yes Steve Model (YSM)** 模型资源仓库，收录了多种风格的角色模型，持续更新中。

## 使用方法

1. 安装 [Yes Steve Model](https://modrinth.com/mod/yes-steve-model) 模组
2. 从本仓库下载你需要的模型文件（`.ysm` 或 `.zip`）
3. 将 `.ysm` 文件放入游戏的 `config/ysm/models/` 文件夹
4. 对于 `.zip` 文件，解压后将内容放入对应目录
5. 启动游戏，在 YSM 模型选择界面中选择模型即可
